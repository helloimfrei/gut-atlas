KEY FINDINGS:
--------------------------------------------------------------------------------
1. XGBoost achieved the best overall performance (Test ROC AUC: 0.8353)
2. Gradient boosting models (XGBoost, LightGBM) significantly outperformed
   logistic regression and deep learning approaches
3. All models achieved ROC AUC > 0.77, demonstrating that microbiome
   composition alone is highly predictive of GI disease risk
4. Patient metadata (BMI, age, region) were excluded due to missing data
5. Lachnospiraceae (butyrate producers) emerged as strongly protective
6. Compression ratio for DAE: 5.1x (2597 features → 512 dimensions)


NOTES:

- All models trained on same 2,597 bacterial taxa after preprocessing
- Preprocessing: TSS → CLR transformation → dead feature removal → filtering
- Test set (n=2,897) was held out and never used for training
- All metrics reported on the same stratified test set
- Class imbalance: 64.2% healthy, 35.8% disease
